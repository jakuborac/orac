# Jakub Oráč | Portfólio

Toto je osobné portfolio webové sídlo pre Jakuba Oráča. Stránka prezentuje profil, projekty, stručné informácie o autorovi a kontaktné údaje v modernom, responzívnom dizajne.

## Obsah projektu

- `index.html` — hlavná štruktúra stránky a obsah jednotlivých sekcií
- `styles.css` — dizajn, layout, farby, typografia a responzívne štýly
- `script.js` — mobilné menu a animácie pri scrollovaní
- `img/` — ikony, favicon a ďalšie grafické súbory
- `docs/` — dokumentácia a referenčné materiály projektu

## Čo stránka obsahuje

- hero sekcia s titulkom a CTA tlačidlami
- sekcia projektov s ukážkami prác
- sekcia „O mne“
- kontaktný blok
- responzívna navigácia pre mobilné zariadenia
- animácie pri vstupe prvkov na obrazovku
- favicon v SVG a PNG formáte

## Ako spustiť

1. Otvori projekt v VS Code.
2. Otvor súbor `index.html`.
3. Použi náhľad v editori alebo spusti stránku v prehliadači.

Pre lokálny preview stačí otvoriť HTML súbor alebo použiť Live Preview/Show Preview v editori.

## Technológie

- HTML5
- CSS3
- JavaScript

## Účel projektu

Webová stránka slúži ako digitálny profil autora a prezentuje jeho prácu, zručnosti a kontaktné údaje v čistom a profesionálnom štýle.
